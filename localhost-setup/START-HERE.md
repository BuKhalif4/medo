# تشغيل Bag City على localhost (بالترتيب)

## قبل لا تبدأ (مرة وحدة)
- GTA V نسخة PC + برنامج **FiveM** مثبّت (fivem.net).
- **مفتاح ترخيص مجاني:** ادخل keymaster.fivem.net بحساب Cfx.re، واضغط Register a new server، وانسخ المفتاح.
  (لو طلب IP اكتب IP جهازك. لو طلع خطأ بالمفتاح بعدين، أرسله لي نصاً بدون المفتاح نفسه.)

## الخطوات
1. نزّل المشروع: GitHub ← مستودع `BuKhalif4/medo` ← فرع `ccr-16df61ab-q90u8v` ← Code ← Download ZIP ← فك الضغط.
2. افتح مجلد `localhost-setup` وشغّل **`setup.bat`** (دبل كليك).
   يحمّل السيرفر والملفات الأساسية، وينسخ `bagcity`، ويسألك عن المفتاح.
   لو فشل التحميل التلقائي بيكتب لك الخطوات اليدوية، وهي قصيرة.
3. بآخر `setup.bat` اكتب `y`، أو شغّل **`C:\FXServer\play.bat`**: يشغّل السيرفر في نافذة، وبعد 30 ثانية يفتح FiveM ويدخلك عليه تلقائياً.
   لازم تظهر في نافذة السيرفر `framework: standalone`. (لا تسكّر نافذة السيرفر.)
   لو ما دخلك تلقائياً: افتح FiveM، اضغط F8، واكتب `connect localhost:30120`.
5. بعد أي تحديث للإضافة: نزّل الـ ZIP من جديد، وشغّل `setup.bat` (مفتاحك محفوظ، ما يسألك مرة ثانية)، ثم `play.bat`.

## المفاتيح (تتغير من إعدادات FiveM ← Key Bindings)
| المفتاح | الوظيفة |
|---|---|
| **F5** | القائمة الدائرية (كل شيء منها، بالماوس أو بالأرقام 1-9) |
| **F6** | لبس/شيل القناع بسرعة |
| **F7** | رمي الحقيبة |
| **E** | التفاعل (سطو، تبييض، تخبئة، التقاط، دخول الخدمة) |
| **G** | الشرطة: اقتحام مخبأ |
| **Esc** | إغلاق / رجوع |

## سيناريو التجربة (لوحدك، بدون لاعب ثاني)
1. **F5 ← تبويب ⚙️ أدوات التجربة ← انتقال سريع ← مركز الشرطة.** اضغط `E` للدخول في الخدمة.
2. **F5 ← انتقال سريع ← بقالة ستروبري.** اضغط `F6` للقناع، ثم `E` وانتظر 12 ثانية للسطو.
3. **F5 ← حقيبتي** تشوف رقمها وقيمتها وحرارتها (فوق على اليمين فيه شريط حالة).
4. **التخبئة:** انتقل لـ«بيت آمن»، واضغط `E` لتخبئة الحقيبة وتبريدها، و`E` مرة ثانية للاسترجاع.
5. **المداهمة:** وانت في الخدمة قف عند البيت واضغط `G` (20 ثانية). غيرك يقدر يقاطعك لو ابتعدت.
6. **التبييض:** انتقل لـ«تاجر الميناء» واضغط `E`. يوصلك رصيد (F5 ← رصيدي).
7. **القبض:** وانت شرطي: F5 ← 🛡️ ← قبض ← اختر نفسك (وضع التجربة يسمح). تظهر لك قائمة 🚨: استسلام أو رشوة.
8. **الأدلة:** F5 ← 🛡️ ← قائمة الأدلة ← اضغط أي حقيبة لتقرأ سجلها.
9. **الصحفي:** F5 ← 📰 ← دخول كصحفي ← تصوير ← نشر خبر.
10. **الحدود:** اركض خارج دائرة المدينة (الدائرة الحمراء على الخريطة): تحذير 12 ثانية ثم يرجعك لمركز الشرطة.

## لو صار خطأ
انسخ لي السطر الأحمر من نافذة السيرفر (أو من F8 في اللعبة) وأنا أصلحه.
هذا أول تشغيل داخل FiveM فعلياً، فتوقّع أشياء صغيرة: القناع، موضع الحقيبة، أيقونات الخريطة، إحداثيات تحتاج ضبط.
