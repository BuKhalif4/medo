# تشغيل Bag City على localhost (بالترتيب)

## قبل لا تبدأ (مرة وحدة)
- GTA V نسخة PC + برنامج **FiveM** مثبّت (fivem.net).
- **مفتاح ترخيص مجاني:** ادخل keymaster.fivem.net بحساب Cfx.re، واضغط Register a new server، وانسخ المفتاح.
  (لو طلب IP اكتب IP جهازك. لو طلع خطأ بالمفتاح بعدين، أرسله لي نصاً بدون المفتاح نفسه.)

## الخطوات
1. نزّل المشروع: GitHub ← مستودع `BuKhalif4/medo` ← فرع `ccr-16df61ab-q90u8v` ← Code ← Download ZIP ← فك الضغط.
2. افتح مجلد `localhost-setup` وشغّل **`setup.bat`** (دبل كليك).
   يحمّل السيرفر والملفات الأساسية، وينسخ `bagcity`، ويسألك عن المفتاح.
   لو فشل التحميل التلقائي بيكتب لك الخطوات اليدوية، وهي قصيرة.
3. شغّل **`C:\FXServer\start.bat`** واتركه مفتوحاً (هذا السيرفر). لازم يظهر فيه `framework: standalone`.
4. افتح FiveM، واضغط F8، واكتب: `connect localhost:30120`
5. بعد أي تحديث للإضافة: نزّل الـ ZIP من جديد، وشغّل `setup.bat`، ثم أعد تشغيل `start.bat`.

## سيناريو التجربة (لوحدك، بدون لاعب ثاني)
اكتب بالشات (زر T):

| الأمر | ماذا يصير |
|---|---|
| `/bc_tp store1` | ينقلك لبقالة |
| `/mask` | تلبس القناع |
| اضغط `E` وانتظر 12 ثانية | سرقة |
| `/bag` | رقم الحقيبة وقيمتها وحرارتها |
| `/bc_tp l1` ثم `E` | تبييض عند التاجر (يوصلك رصيد: `/balance`) |
| `/myid` | رقمك (مثلاً 1) |
| `/duty` ثم `/arrest 1` | تقبض على نفسك |
| `/bribe 10000` ثم `/acceptbribe` | رشوة، وتبقى الحقيبة معك |
| `/ledger` | سجل الرشاوى |
| `/evidence BC-xxxxxx` | سجل حياة الحقيبة (بعد مصادرتها أو تبييضها) |
| `/press` ثم `/snap` ثم `/publish سطو على البقالة` | الصحفي |

## لو صار خطأ
انسخ لي السطر الأحمر من نافذة السيرفر (أو من F8 في اللعبة) وأنا أصلحه.
ما أتوقع أخطاء كبيرة، لكن هذا أول تشغيل داخل FiveM فعلياً، فتوقّع أشياء صغيرة (قناع ما يظهر، موضع الحقيبة، إحداثية بعيدة...).
