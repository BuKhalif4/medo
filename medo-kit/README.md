# طقم ميدو (MDK)

ست **سكربتات** (وحدات) في مورد واحد اسمه `mdk`، كلها تُدار من **لوحة تحكم واحدة** (F5):

| السكربت | وظيفته |
|---|---|
| **zone** الحدود والأماكن | حدود المدينة، وتحديد نقاط الأماكن من اللعبة |
| **bag** الحقيبة وسجلها | القناع، السطو، الحقيبة الحية بسجل حياتها، التبييض، التخبئة |
| **police** الشرطة | الخدمة، الرتب والمعدات، القبض والاستسلام والرشوة، الأدلة، المداهمة |
| **press** الصحافة | تصوير أحداث حقيقية ونشرها (تسخّن الحقيبة) |
| **market** السوق والشحنات | السوق السوداء، شجرة الشحنات، التجهيز، الذخيرة والتعديلات |
| **party** المجموعة | دعوة لاعبين (حتى 3) وعلامات الأعضاء على الخريطة |

## لوحة التحكم (F5)
- **الرئيسية:** ملخص حالتك وإجراءات سريعة.
- **صفحة لكل سكربت** مفعّل (الحقيبة، السوق والشحنات، الشرطة، الصحافة، المجموعة).
- **للأدمن** (`mdk.admin`): **السكربتات** (تفعيل وإيقاف كل واحد مباشرة بدون إعادة تشغيل)، و**الإعدادات** (18 قيمة قابلة للتعديل: أسعار ونسب ومدد، تنحفظ للأبد)، و**الإحصاءات** الحية.
- **للمطوّر** (`mdk.dev`): أدوات التجربة (انتقال، تحديد النقاط، كاش).

## إضافته لأي سيرفر موجود
1. انسخ مجلد `mdk` إلى `resources` عندك.
2. أضف في `server.cfg`: `ensure mdk`
3. أعطِ الصلاحيات للمسؤولين: `add_ace group.admin mdk.admin allow` وللتجربة `mdk.dev`.
4. للشرطة والصحافة في الوضع المستقل: `mdk.cop` و`mdk.press` و`mdk.ia`.
- **الإطارات:** يكتشف تلقائياً **Qbox أو QBCore أو ESX** (للكاش والبنك والوظيفة)، وإلا يشتغل مستقلاً برصيد داخلي.
- لو سيرفرك عنده سكربتات شرطة أو سوق ثانية، عطّل السكربت المقابل من لوحة التحكم بدل ما يتعارضون.

## التصميم الداخلي
- `server/core.lua`: بوابة إجراءات واحدة بقائمة بيضاء، سجل الوحدات، الإعدادات المحفوظة، لوحة التحكم.
- `server/m_*.lua` و`client/m_*.lua`: كل سكربت لوحده. تتواصل عبر `K.*` (الخادم) و`KC.*` (العميل).
- **حماية:** السيرفر هو الحاكم؛ مدخلات تُنظَّف؛ حد معدل؛ أحداث فخ؛ المخالفة القديمة تنمسح؛ والأدمن يُتحقق منه بصلاحية ACE (ليس بما يرسله العميل).
- الواجهة: أي نص من لاعب يُعرض كنص فقط (لا ثغرات حقن).
