# MEDO Boost

برنامج تسريع وتنظيف ومراقبة لجهازك، مصنوع خصيصاً لك. الكود كله هنا وتقدر تقرأه.

> ⚠️ أول مرة تشغّله رح يطلع لك «Windows protected your PC» لأن البرنامج غير موقّع بشهادة مدفوعة.
> اضغط **More info ← Run anyway**. البرنامج يطلب صلاحية مسؤول (Admin) لأنه ينظف مجلدات النظام ويعدّل الخدمات.

## الأقسام

| القسم | شو يسوي |
|---|---|
| **الرئيسية** | عدادات حية للمعالج والكرت والرام والقرص + الحرارة والسرعات والطاقة + رسم بياني + «صحة الجهاز» + تحسين بضغطة وحدة |
| **تنظيف من الصفر** | بروفايل «ألعاب + برمجة» بضغطة وحدة: نقطة استعادة ← التويكات ← حذف تطبيقات Windows الزائدة (News، Cortana، Teams، Xbox، Candy Crush…) ← حذف OneDrive ← تنظيف عميق. ما يلمس المتجر و winget و WSL و Docker و VS Code |
| **التنظيف العميق** | +40 عنصر: Temp، كاش تحديثات Windows، Crash dumps، السجلات، كاش الشيدر (DirectX / NVIDIA / AMD / Intel)، Steam / Epic / Battle.net / EA / Riot، كل المتصفحات، Discord / Spotify / Teams / Telegram / VS Code… أنت تختار شو ينحذف |
| **البرامج والرامات** | كل برنامج شغال مع الرام / CPU / GPU، تخفيف رام برنامج، **مسح كاش** (يسكر البرنامج ← يحذف الكاش ← يرجع يفتحه)، إنهاء، تغيير الأولوية |
| **تسريع وتويكات** | ~55 تويك (ألعاب، أداء، شبكة، خصوصية، خدمات، برمجة: Long Paths، وضع المطور، تحديد رام WSL). كل تويك يحفظ القيمة الأصلية وترجعه بإطفاء المفتاح |
| **بدء التشغيل** | تعطيل وتفعيل البرامج اللي تشتغل مع Windows (نفس طريقة Task Manager) |
| **FPS والأوفرلاي** | عداد FPS بدون حقن (آمن مع الأنتي تشيت)، أوفرلاي فوق الشاشة، **قياس قبل وبعد** مع متوسط FPS و 1% Low |
| **أدوات الإصلاح** | SFC، DISM، CHKDSK، TRIM للـ SSD، إعادة ضبط الشبكة، نقطة استعادة… |
| **السجل** | كل عملية يسويها البرنامج تنكتب هنا |

## الاختصارات (شغالة حتى وانت داخل اللعبة)
- `Ctrl + Shift + F` تشغيل/إخفاء الأوفرلاي
- `Ctrl + Shift + B` بدء/إيقاف قياس الأداء
- `Ctrl + Shift + G` Game Boost (تحرير رام + إغلاق البرامج اللي اخترتها)

## الأمان: شو ما يلمسه البرنامج أبداً
- ملفاتك الشخصية، الصور، المستندات، الألعاب، ملفات الحفظ
- كلمات السر والكوكيز (سجل التصفح اختياري ومطفي افتراضياً)
- ما يحذف أي مجلد رئيسي، بس **محتوى** مجلدات الكاش. ولا يتبع الاختصارات (junctions) لبرا المجلد
- الملفات المستخدمة حالياً يتم تخطيها
- ما يتصل بالإنترنت ولا يرسل أي بيانات

## وين تلاقي سجلات البرنامج
`%LOCALAPPDATA%\MedoBoost\`
- `logs\deleted-files-YYYY-MM-DD.txt`: قائمة بكل ملف انحذف
- `logs\log-YYYY-MM-DD.txt`: كل عملية
- `backup.json`: القيم الأصلية لكل تويك (عشان الإرجاع)
- `startup-backup\`: نسخ من اختصارات بدء التشغيل المحذوفة

## حرارة المعالج
الحساسات من مكتبة [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) المفتوحة المصدر.
حرارة كرت الشاشة تشتغل مباشرة. حرارة **المعالج** تحتاج تعريف [PawnIO](https://pawnio.eu/)، وهو تعريف موقّع ومفتوح المصدر.
البرنامج القديم WinRing0 صار Windows Defender يحظره من 2025، فما استخدمناه.

## الأوفرلاي
يشتغل فوق الألعاب بوضع **Borderless / Windowed**. الألعاب بوضع Fullscreen الحقيقي (Exclusive) ترسم فوق كل النوافذ، فحوّل اللعبة لـ Borderless.

## البناء من الكود
```
dotnet publish MedoBoost/MedoBoost.csproj -c Release -o out
```
يطلع ملف واحد `out/MedoBoost.exe` (self-contained، ما يحتاج تثبيت .NET).
